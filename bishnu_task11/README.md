# Thala 7 Sneaker Store - CSS Mini Project

A 4-page sneaker store mini project implemented with:
- HTML
- CSS only for styling/layout
- Vanilla JavaScript for small interactions
- No Bootstrap

Pages:
1. index.html - Landing Page
2. product.html - Product Display
3. cart.html - Shopping Cart
4. payment.html - Payment / Checkout

Features:
- Flexbox and CSS Grid
- Responsive design
- Product gallery
- Quantity controls
- Add to cart
- localStorage cart
- Coupon demo: THALA7 (10% discount)
- Checkout summary

Open `index.html` in a browser to start.
