# Greenwood Public Library

A responsive editorial-style library landing page built with:
- HTML
- Tailwind CSS via CDN
- Small vanilla JavaScript for the mobile menu
- No custom CSS framework and no external font

Open `index.html` directly in a browser.

The page follows the supplied reference screenshots and requirements:
navbar, hero, stats, sections grid, gallery, bento values, editorial about section,
membership cards, testimonial, contact CTA, events grid, responsive footer, hover
animations, image zoom, grayscale transition, and mobile navigation.
